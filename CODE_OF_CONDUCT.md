# Code of conduct

Ontos adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) verbatim.

Short version: treat other contributors with respect. Assume good faith. Disagree on technical merits, not on people. Harassment, personal attacks, and discriminatory behavior are not tolerated and will result in a ban from the project.

## Reporting

Violations can be reported confidentially to **contact@getenclave.ai** with the subject line `[Ontos CoC]` so ops can route it to the maintainers. Reports are handled per the Contributor Covenant enforcement guidelines. We will not publicly identify a reporter without their explicit consent.

## Scope

This code of conduct applies in all project spaces — GitHub repository, issues, PRs, Discussions, any project-affiliated chat (Discord/Slack) — and in any public space when an individual is representing the project.
